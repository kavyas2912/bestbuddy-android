# BestBuddy Android — V1.08.0 M1 source candidate (not a release)

Baseline: supplied V1.07.6 complete source, preserved separately.

## Implemented
- Default companion tone for **new users** changed from playful to calm.
- Default visual theme for **new users** changed to the existing solid Emerald Blue theme; accent aligned to that theme.
- Onboarding tone buttons now initialize from persisted user preference, avoiding misleading Playful selection when another tone is stored.
- Existing users retain their saved tone, theme, and accent through the preference override.
- Added `tests/mature-defaults.test.mjs` regression tests.
